### 🦁 Core Research & Projects
현장의 제한된 하드웨어 리소스를 극복하고, 모델 경량화 및 실시간 데이터 처리 파이프라인을 구축하여 실제 산업 도메인의 병목을 해결하는 데 집중합니다.

*   🦅 **[Wafer-Defect-Classification] 반도체 웨이퍼 결함 분류 초경량화 AI 모델 설계**
    *   고차원 특징을 슬라이딩 윈도우 방식으로 분할하고 토큰화하는 모델(SCRBLAA-Net)을 개발했습니다[cite: 3].
    *   VRAM 사용량을 3.2GB로 대폭 절감하면서도 94.98%의 결함 분류 정확도를 달성했습니다[cite: 3]. 
    *   해당 연구 성과를 인정받아 SCIE급 국제 학술지(JCR Q2)에 제1저자로 논문을 게재했습니다[cite: 3].
*   🦊 **[yolo-vision-multi-inspection-coreml] 실시간 다중 차량 인식 경량화 및 트래킹**
    *   엣지 디바이스 환경을 고려해 CoreML 포맷으로 가속 변환하여 파이프라인을 최적화했습니다[cite: 3].
    *   정밀도 손실을 방어하며 추론 지연시간을 기존 대비 31% 단축한 9.05ms로 실시간 탐지를 구현했습니다[cite: 3].
*   🐻 **[mvtecad-anomaly-detection] 비지도 학습 기반 산업용 고정밀 이상 탐지**
    *   정상 데이터만을 활용해 결함을 찾아내는 비지도 학습 기반의 복합 파이프라인을 구축했습니다[cite: 3].
    *   고속 추론용 모델과 정밀 검출용 모델을 병렬 설계하고 하드웨어 메모리를 제어하여, 기본 모델의 고질적인 과검 문제를 해결하고 양품 오분류를 0건으로 차단했습니다[cite: 3].
*   🐺 **[nasa-cmapss-multi-condition] 다중 운전 조건 항공 엔진 예후진단(PHM)**
    *   이종 센서 신호의 왜곡을 방지하기 위해 CNN-BiLSTM-Attention 등 복합 아키텍처를 적용하여 예후진단 패널티 예측 에러를 크게 감축했습니다[cite: 3].
